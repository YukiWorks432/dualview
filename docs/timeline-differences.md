# タイムラインの差分解析

A/Bトラックの動画を比較し、変更された面積がしきい値以上の区間を時間目盛りの下へ表示する。`Analyze differences`で開始し、前後の差分ボタンから区間へ移動する。帯のクリックでもシークできる。赤い区間は解析不能または素材欠落、縞は未解析であり、一致を意味しない。

解析は専用WorkerのMediabunny入力から行い、再生用のvideo要素や共有再生時計を走査しない。素材はサーバーへ送信しない。現在の対象はA/Bトラックの動画であり、画像クリップは解析非対応と表示する。追加トラックを合成した結果や音声は、この差分スコアの対象にしない。

## 判定条件

pixelmatchで、許容色差を超える画素の割合を計算する。`Colour tolerance`は画素ごとの色差許容値、`Difference area (%)`は強調する面積の割合であり、別の設定である。アンチエイリアスも比較に含める。面積しきい値の変更は保存済みスコアから再判定するため、再デコードしない。色差許容値や解像度の変更後は、手動で再解析する。

標準設定は色差許容値0.1、差分面積1%、長辺640pxを上限とする縮小比較。これらは初期評価値であり、あらゆる圧縮設定や映像に対して検証済みの保証値ではない。詳細設定ではA/Bに共通して利用できる解像度で比較する。小さい側を拡大せず、両側の表示幅・高さの小さい値を共通枠に使い、アスペクト比を保って収める。縦横比が違うと余白も差分になり得る。

どちらの設定も、A/Bの表示時刻と継続時間をタイムラインへ対応付け、どちらかの表示フレームが変わる境界で比較する。トリミング、配置、定速変更、逆再生を反映し、固定FPSや0.5秒間隔のサンプリングへ置き換えない。境界の丸め誤差を除くため、1ナノ秒未満の数値差だけを同じ境界として扱う。区間は開始を含み終了を含まない。

色は黒背景へ合成した見た目を比較し、アルファ差の画素集合を加える。同じ画素を二重に数えず、完全透明部分の隠れたRGBだけが違う場合は差分にしない。デコード時の回転情報を反映する。プレビューのズーム、ROI、位置合わせ、比較モードの見た目は適用しない。表示変換後の8bit比較なので、HDR・高ビット深度の信号品質の保証には使用しない。

## 結果と資源

しきい値を超えた連続区間だけをまとめ、1フレームだけの異常も残す。平滑化、短い区間の自動除外、未解析区間をまたぐ結合は行わない。ズームアウト時は画面上の1pxごとの最大差分を表示するが、区間の実際の時刻は変更しない。

結果はセッション内だけに保持する。ページの再読み込みで消える。素材の実体、配置、In/Out、速度、逆再生、プロジェクトの変更は結果を失効させる。単なるズーム・スクロール・表示モードの変更では失効しない。中止後の結果は受信済み部分だけであり、完了表示にはしない。

デコードした全フレーム画像は保存しない。保持するのは素材のフレーム時刻一覧、解析済みの数値、区間であり、これらのメモリー量は動画の長さに応じて増える。フレーム画像は少数のCanvasを再利用する。中止はWorkerを終了してデコーダーも破棄する。逆再生や長いGOPのランダムデコードは遅くなる場合がある。

## 検証

`pnpm check`は既存の整形、Lint、型チェック、Vitest、ビルドを実行する。計算のテストは、表示時刻の対応、1フレームの異常、平坦な差分区間、欠落、透明度、画面幅への集約、結果失効を検証する。

ブラウザーテストにはFFmpegとPlaywright Chromiumを用意し、`pnpm exec playwright install chromium`、`pnpm test:browser`を実行する。`scripts/create-difference-fixtures.mjs`で小さな合成動画を作成するため、大きなバイナリー素材をリポジトリへ追加しない。通常動画、ProResとの混在、VFR、局所変更、素材欠落、しきい値変更を、実際のデコードとUIを経由して確認する。

合成動画の成功だけで圧縮ノイズへの一般的な耐性は保証しない。実際の納品素材でのしきい値調整、長時間・高解像度素材の処理速度と最大メモリー、対象ブラウザーごとの確認は別途必要。測定していない性能値は掲載しない。
