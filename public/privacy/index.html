日本語

素材の処理

ローカルファイルとして選択、ドラッグ＆ドロップ、画像貼り付け、または画面キャプチャで取り込んだ 画像・動画・動画内音声は、この端末のブラウザー内で比較、解析、書き出し処理を行います。 ファイル名、サムネイル、比較結果、解析結果も通常の素材処理の一部としてブラウザー内で扱います。

DualView には、これらのローカル素材を運営者が閲覧するためのアップロード機能はありません。 素材を処理するために、その権利を YukiWorks432 へ譲渡したり、包括的な利用許諾を与えたりする必要もありません。

画面キャプチャは、利用者の操作とブラウザーの許可に基づいて素材を取り込む機能です。 キャプチャした素材をサーバーへ送信する機能ではありません。

ブラウザー内の保存と削除

DualView は IndexedDB を使い、プロジェクト設定、素材のメタデータ、サムネイル、 素材本体をこのブラウザープロファイル内に保存します。素材、タイムライン、設定の変更は自動保存され、 手動の保存操作も利用できます。タブを閉じるだけでは保存済みデータは削除されません。

共有端末では、同じブラウザープロファイルを使う別の利用者が保存済みプロジェクトを開ける可能性があります。 保存容量の不足、プライベートブラウジング、ブラウザーによるデータ消去、利用者によるサイトデータ削除などにより、 保存や復元ができない場合があります。DualView は保存データのバックアップを保証しません。

プロジェクト単位の削除は Projects 画面から行えます。サイトに保存されたデータ全体を消したい場合は、 ブラウザーのサイトデータ削除機能を利用してください。これらの操作は、元のローカルファイル、 すでにダウンロードした書き出しファイル、別のブラウザーや別プロファイルのデータまで削除するものではありません。

.dualview プロジェクトファイルには素材本体が Base64 データとして含まれます。 設定だけのファイルではなく、暗号化形式でもありません。第三者へ送付・公開する前に、 含まれる素材を確認してください。

サイト配信と外部通信

素材のローカル処理と、ウェブサイトを利用するために必要な通信は別のものです。 現在の公開サイトでは、主に次の通信が発生します。

通信 送信先 情報・目的・発生タイミング
サイト・追加プログラムの読み込み DualView の配信基盤である Cloudflare IPアドレス、要求URL、ブラウザーが通常送る通信情報など。サイト配信、通信処理、 セキュリティのため、ページや必要なプログラムを取得するときに発生します。
URLからの取り込み 利用者が指定した取得先と、そのリダイレクト先 IPアドレス、要求URLなど。利用者が Import を実行して指定素材を取得するときに発生します。 取得後の比較・解析は端末内で行います。
外部リンク 利用者が開いたリンク先 リンクを開いた後の通信や情報の取り扱いには、リンク先サイトの説明や プライバシーポリシーが適用されます。

URL取り込みは、ブラウザーから取得先へ直接接続します。認証情報を付けない credentials: 'omit' と、参照元を送らない referrerPolicy: 'no-referrer' を使用していますが、 接続先から完全に匿名になることを保証するものではありません。 取得先がリダイレクトした場合は、そのリダイレクト先にも通信します。 選択済みの別のローカル素材を取得先へ送る処理はありません。

Cloudflare の配信・セキュリティ機能では、アクセス時の通信情報や Cookie が取り扱われる場合があります。このページは「アクセスログが存在しない」「Cookie を一切使わない」 「すべての処理が日本国内だけで完結する」とは保証しません。

English

Media processing

Images, videos, embedded video audio, file names, thumbnails, comparison results, and analysis results imported through the file picker, drag and drop, image paste, or screen capture are processed in the browser on this device. DualView does not provide an upload path that lets the operator inspect those local media files, and using the tool does not require transferring ownership of the media or granting the operator a broad license.

Screen capture occurs only after your action and the browser's permission flow. It is an import source, not a server upload feature.

Storage and deletion in your browser

DualView stores project settings, media metadata, thumbnails, and media blobs in IndexedDB in the current browser profile. Media, timeline, and setting changes are saved automatically, and manual save is also available. Closing the tab alone does not remove saved data.

Someone using the same browser profile on a shared device may be able to open saved projects. Storage limits, private browsing, browser eviction, or clearing site data can prevent saving or recovery. DualView does not guarantee a backup.

Delete individual projects from the Projects screen, or use your browser's site-data controls to remove the site's stored data. These actions do not delete your original local files, files you already downloaded, or data held by another browser or profile.

A .dualview project file contains the media itself as Base64 data. It is not a settings-only file and is not encrypted. Check its contents before sharing or publishing it.

Site delivery and external communication

Local media processing is separate from the network traffic required to use a website. Loading the site and additional program files contacts Cloudflare, the delivery provider, and normal web requests can disclose information such as your IP address, requested URL, and browser-supplied network metadata for delivery, processing, and security.

URL import is user initiated and connects your browser directly to the destination you enter and any redirect destination. Those sites can receive your IP address and the requested URL. DualView uses credentials: 'omit' and referrerPolicy: 'no-referrer', but this does not make the request fully anonymous. Other local media you selected is not sent to the URL-import destination.

Following an external link is governed by the destination site's own privacy information. Cloudflare may process network information or cookies as part of delivery and security, so this page does not claim that there are no logs or cookies, that all processing occurs only in Japan, or that a particular retention period applies.
