プライバシーとデータの取り扱い

素材を処理する場所、ブラウザー内の保存、サイト利用時に発生する通信について説明する。

日本語 · English

施行日: 2026年9月29日 · 文書更新日: 2026年10月2日

日本語

素材はブラウザー内で処理する

読み込んだファイルはサーバーへアップロードせず、ブラウザー内で処理する。

ファイル選択、ドラッグ＆ドロップ、画像貼り付け、画面キャプチャで読み込んだ画像・動画は、この端末のブラウザー内で比較・解析・書き出しを行う。これらのローカル素材を運営者へアップロードする機能はない。

保存と削除

プロジェクトと素材は、このブラウザー内に自動保存する。保存済みのデータはタブを閉じても残り、後から作業を再開できる。

個別のプロジェクトはProjects画面から削除できる。サイト内の保存データをすべて消す場合は、ブラウザーのサイトデータ削除機能を使う。重要な素材とプロジェクトは、必要に応じて別途バックアップする。

書き出した.dualviewファイルには素材そのものも含まれる。第三者へ共有する際は、元の素材と同じ注意で取り扱う。

サイト利用時の通信

サイトの表示と安全な配信には、配信基盤のCloudflareとの通常の通信が必要になる。この過程で、IPアドレスなど一般的なウェブ通信情報が取り扱われる場合がある。

URL取り込みでは、入力したURLへブラウザーから直接接続する。取得後の素材の比較・解析は端末内で行い、別に読み込んでいるローカル素材を取得先へ送信することはない。

書体の表示にはAdobe Fontsを使う。フォントデータを取得する際にAdobeのサーバーへ接続する。

English

Effective: September 29, 2026 · Document updated: October 2, 2026

Local processing

Loaded files are processed in the browser without being uploaded to a server.

Images and videos added by file selection, drag and drop, image paste, or screen capture are compared, analyzed, and exported in this browser on your device. The application has no feature that uploads these local sources to the operator.

Storage and deletion

Projects and media are saved automatically in this browser. Saved data remains after the tab closes so work can be resumed.

Delete individual projects in Projects, or use your browser’s site-data controls to remove all data stored for this site. Keep separate backups of important media and projects as needed.

An exported .dualview file includes the media itself. Share it with the same care as the original sources.

Network connections

Loading and securely delivering the site requires normal connections to Cloudflare. Standard web connection information, including an IP address, may be processed by that service.

URL import connects the browser directly to the entered URL. Comparison and analysis then happen on this device; other local sources already loaded in DualView are not sent to that destination.

Adobe Fonts supplies the interface typefaces. Fetching font data connects the browser to Adobe’s servers.
