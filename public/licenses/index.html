English

DualView application

The repository-root LICENSE is the canonical license for DualView. It retains the MIT License notice, including Copyright (c) 2025 DualView Contributors, rather than replacing it with the maintained-fork operator's name.

Bundled third-party dependencies

Production builds use Vite build.license to generate licenses/third-party.md from dependencies actually included in the bundle. This avoids maintaining a second hand-written dependency list as the source of truth.

Copied assets, dynamic loading, and WASM

Additional notices cover distributed files that are not fully represented by the normal bundle notice. They currently include the copied gif.worker.js file and the fixed corresponding source for @mediabunny/prores 1.59.0. Components covered by MPL-2.0 remain under MPL-2.0; this does not relicense the overall DualView application away from MIT.
