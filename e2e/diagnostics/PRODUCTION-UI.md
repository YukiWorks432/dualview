# 製品版での音声取消・入力応答の反復測定

#73 の測定手順です。性能合格の判定や製品修正を含みません。既存の
`audio-budget.e2e.ts` による実タイマー・実 AudioBuffer の取消契約を維持します。
通常の品質確認や CI の代わりにはなりません。

## 実行

リポジトリ指定の Node / pnpm、固定依存関係と対応する Chromium を使います。
既存の合成 `e2e/fixtures/audio-long.webm` を A/B に読み込みます。

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install --with-deps chromium
node e2e/diagnostics/production-ui.mjs test-results/production-audio-ui-1
```

既存の保存先は上書きせず失敗します。失敗した試行も保存し、再実行する場合は
別の保存先を指定してください。既に用意した同じ版の実行ファイルを選ぶ時だけ
`BROWSER_EXECUTABLE_PATH` を設定できます。起動は常にサンドボックス有効です。
ポート 4178 を専用に使い、既存サーバーへ接続しません。

計測前に他のビルド・ブラウザー試験を止め、記録に実際の同時負荷と統制限界を
併記してください。共有ホストの負荷や電源状態はこの手順では固定できません。
4倍の CPU 制限は DevTools の制限であり、外部 CPU 負荷や代表的な低性能端末を
再現するとは限りません。利用者の端末や許容待ち時間の合意は別途必要です。

## 試行と成果物

実行前に `plan.json` を保存します。各反復は通常取消→通常完了→4倍取消→4倍完了、
3反復で計12試行です。途中の失敗で順序を変えず、自動再試行はしません。
ブラウザーは共有し、試行ごとに新しいコンテキスト・ページを作ります。
初回はページ内の音声処理が初回という意味で、ディスク等のキャッシュは共有です。
同じページでの再処理、ProRes、入力上限近傍はこの系列に含みません。

製品用の Vite ビルドへ試験専用の呼出し観測を追加します。製品ソースの変更や
開発版の React 処理は含みませんが、計測による負荷はあります。
処理を保留するフックは使わず、解析開始を通知したら実ポインターで Slider を
クリックします。到着時点で A の解析中・B 待機中でなければ試行は無効です。
解析の AbortError、作業終了後の枠解放、Slider 表示をそれぞれ観測します。
45秒は試行の資源制限であり、合格の遅延基準ではありません。

- `plan.json`: 対象 SHA、未コミット状態、スクリプト・固定依存関係・素材のハッシュ、
  実ブラウザー版、OS・CPU・メモリー、事前の試行順序
- `results.json`: 失敗・ページエラーを含む全試行、ページ時計のイベント、別時計の
  入力要求・復帰、条件別の全生値と件数・欠測数・最小値・中央値・最大値
- 各試行の PNG と計測用 `dist/`: 終了表示と測定したビルド

3試行から上位分位や一般的な保証は推定しません。失敗は集計値から除外して件数を
残し、欠測をゼロにしません。全試行の終了後、無効試行やページエラーがあれば
非ゼロ終了します。起動・ビルド自体の失敗には試行記録がない場合があります。

## 区間の意味

取消の DOM 到着→その解析の signal に対する abort 呼出し、abort→解析拒否、
DOM 到着→待ち列の枠解放、DOM 到着→画面更新後の2回目のフレーム機会を分離します。
2回の requestAnimationFrame は物理画面への提示完了を示しません。DOM 到着前の
物理入力配送も測っていません。試験ドライバーとページの時計を引き算しません。

完了試行は Audio QA クリックの DOM 到着→A/B 結果のフレーム機会を記録します。
アップロード・素材準備は含まれません。監視タイマーは開始・終端を含む最大間隔を
別指標として残し、入力応答時間と取り違えません。JavaScript ヒープの始終値も
プロセスの最大メモリーではありません。常駐量の別測定は #77 で扱います。

この基盤の統合だけでは #73 を閉じません。同じ端末・素材・依存関係・負荷での
変更前後比較、代表条件・許容時間・処理全体時間の受入基準の合意が残ります。
